# Post assets

Media for the write-up about this project, served over GitHub Pages so the
files can be embedded from platforms that do not host video themselves
(dev.to allows a `<video>` tag but will not accept an mp4 upload).

| File | Used for |
|---|---|
| `media/hero-streaming.mp4` | the demo clip — two typed questions and a button press, each re-forming the same canvas |
| `media/hero-streaming.gif` | same clip, for platforms that strip video (Medium) |
| `media/generated-dark.png` | a generated answer: stat cards, chart, model-written buttons |
| `media/recomposed-dark.png` | the canvas after a button press |
| `media/cover.png` | 1000×420 cover image |

All of it was captured from the running app, not mocked up.
